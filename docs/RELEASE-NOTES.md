# Draft release notes — Botburn 0.1.0

**Status:** draft for pull-request review. **Not** published as a GitHub
Release or git tag.

## 0.1.0 — early public kit

First public community skill for finding where Grok Bot usage went across
**all** tasks (chats, routines, coaching, ops, drafts, shipping, social —
not only coding).

### Included

- [`SKILL.md`](../SKILL.md) — managed **usage-review** first; managed
  **canvas** for dashboards (TLDR → largest-first charts → drilldowns only
  with actual data → source details below)
- [`README.md`](../README.md) — TLDR, fictional visual sample, install by
  attaching the skill, deep-dive, reporting limitations
- MIT license
- Synthetic examples and SVG/PNG sample
- [`docs/methodology.md`](./methodology.md) and static QA
- `python3 scripts/validate.py` and `--selftest` (stdlib only; negative fixtures)

### Not in this draft

- No GitHub Release / tag until PR review
- No live account audits and no private Page URLs
- Not an official xAI / Grok / Cursor product
- No claimed savings, token counts, or all-account test coverage
- No separate app to deploy

### Install

Attach [`SKILL.md`](../SKILL.md) in a Grok Bot chat and ask to save it as
Botburn. Source: [github.com/apwn/botburn](https://github.com/apwn/botburn)
